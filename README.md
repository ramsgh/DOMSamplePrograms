# Day 16: DOM Manipulation - Small Programs

This project contains 5 individual HTML/JS programs explaining core DOM Manipulation concepts:

1. `01-selecting-elements.html` -> `document.getElementById`, `querySelector`, `querySelectorAll`
2. `02-text-and-content.html` -> `innerHTML`, `textContent`, `innerText`
3. `03-styles-and-classes.html` -> `style.property`, `classList.add / remove / toggle`
4. `04-creating-and-inserting.html` -> `createElement`, `appendChild`, `insertBefore`
5. `05-removing-elements.html` -> `remove()`, `removeChild()`

## How to Run:
- Double-click any `.html` file to open it in your web browser!
- Or open the folder in VS Code and use the **Live Server** extension.
